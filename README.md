一、畢業專題報告名稱
中文名稱：結合生成式人工智慧與地理資訊之智慧旅遊行程規劃系統
英文名稱：A Smart Travel Itinerary Planning System Integrating Generative Artificial Intelligence and Geographic Information
題目說明
本專題旨在整合生成式人工智慧（Generative AI）與地理資訊系統（Geographic Information System, GIS），開發一套能依據使用者旅遊需求，提供景點推薦、行程安排、地圖呈現及路線檢核的智慧旅遊行程規劃系統。使用者可輸入旅遊地點、日期、天數、交通方式、預算及興趣偏好，系統再結合景點資料、地理座標與交通資訊，產生較符合實際旅遊條件的行程。
為降低生成式 AI 可能產生不正確資訊的風險，系統應設計景點資料驗證與時間可行性檢核機制。本題目兼具人工智慧應用、地理資訊整合與系統實作等特色，適合作為資訊工程、資訊管理或相關領域之畢業專題。
二、畢業專題報告摘要（Abstract）
2.1 中文摘要
隨著生成式人工智慧與地理資訊技術日益成熟，智慧旅遊服務逐漸成為資訊科技應用的重要發展方向。傳統旅遊行程規劃通常需要使用者自行搜尋景點、比較旅遊資訊、安排造訪順序，並評估景點間的交通時間與距離，過程較為繁瑣，且容易因資訊分散或時間估算不當而產生不合理的行程。
本專題旨在設計與實作一套「結合生成式人工智慧與地理資訊之智慧旅遊行程規劃系統」，整合生成式人工智慧的自然語言理解與內容生成能力，以及地理資訊服務的景點定位、距離分析、路線呈現等功能。使用者可輸入旅遊地點、旅遊日期、旅遊天數、交通方式及個人興趣等需求，系統再依據景點資料與使用者條件，產生結構化的旅遊行程，並透過互動式地圖呈現景點位置與建議路線。
為提升行程內容的可靠性與可行性，本系統規劃加入景點資料檢核、交通時間評估及行程時間限制等機制，以降低生成式人工智慧可能產生錯誤景點資訊或不合理安排的情況。系統完成後，將透過功能測試、案例測試及量化評估，檢視景點資料有效性、行程時間可行率、規劃所需時間及使用者滿意度等指標。
本專題期望建立一套兼具自然語言互動、地理資訊視覺化與行程可行性檢核能力的智慧旅遊規劃原型，協助使用者降低旅遊規劃的時間成本，並作為生成式人工智慧與地理資訊技術整合應用之參考。實際研究成果與效益將以系統實作及測試結果為依據。
關鍵詞：生成式人工智慧、地理資訊系統、智慧旅遊、行程規劃、路線分析
2.2 Abstract
With the continued development of generative artificial intelligence and geographic information technologies, smart tourism has become an important application area for information technology. Traditional travel planning often requires users to search for attractions, compare travel information, arrange visiting sequences, and estimate travel distances and durations. These tasks can be time-consuming, particularly when information is scattered across different sources or when itinerary schedules are unrealistic.
This project aims to design and implement a Smart Travel Itinerary Planning System Integrating Generative Artificial Intelligence and Geographic Information. The proposed system combines the natural language understanding and content generation capabilities of generative AI with geographic information services, including attraction location lookup, distance analysis, route presentation, and map-based visualization. Users can provide travel preferences such as destination, travel dates, trip duration, transportation mode, budget, and interests. Based on these requirements and available attraction data, the system generates a structured itinerary and displays attraction locations and suggested routes on an interactive map.
To improve the reliability and feasibility of generated itineraries, the system is designed to incorporate attraction data validation, travel-time estimation, and schedule constraint checking. These mechanisms aim to reduce the risk of fabricated attraction information and impractical travel arrangements. After implementation, the system will be evaluated through functional tests, scenario-based tests, and quantitative measures, including attraction data validity, itinerary feasibility, planning time, and user satisfaction.
The project is expected to deliver a prototype that integrates natural language interaction, geographic information visualization, and itinerary feasibility checking. It aims to reduce the effort required for travel planning and provide a practical reference for integrating generative AI with geographic information technologies. The actual contributions and effectiveness of the system will be determined by implementation and evaluation results.
Keywords: Generative Artificial Intelligence, Geographic Information System, Smart Tourism, Travel Itinerary Planning, Route Analysis

5.3 主要技術風險
•	AI 幻覺：模型可能產生不存在的景點、錯誤地址或不正確的營業時間，應透過可信資料來源驗證。
•	地理資料品質：景點座標、地址及營業資訊可能不完整或過期，應記錄來源與更新日期。
•	行程可行性：景點順序看似合理，不代表交通時間足夠，應納入移動時間、停留時間、用餐時間及營業時間限制。
•	API 限制：考量請求額度、網路失敗、金鑰管理及服務費用。
•	隱私與資安：API 金鑰應存放於環境變數或安全設定中，不可直接寫入公開程式碼。

8.3 評估指標與計算方式
•	景點有效率：行程中可由可信資料確認的景點比例。
•	路線總距離：各景點之間實際道路距離的總和。
•	交通時間：使用相同路線服務與交通模式取得的估計時間。
•	行程可行率：符合既定時間、營業時間及交通限制的行程比例。
•	行程生成時間：從送出需求至取得可用行程的時間。
•	人工修正量：使用者為了使行程可行而必須修改的項目數。
•	使用者需求符合度與滿意度：評估行程是否符合偏好，以及使用者對品質的主觀評價。
•	API 呼叫次數與成本：評估系統實際營運成本。
景點有效率可定義為：
景點有效率 =（經資料來源確認有效的景點數 ÷ 行程中的景點總數）× 100%
景點有效不等於整段行程可行；即使每個景點都存在，也可能因交通時間、營業時間或停留時間而無法完成。

十三、預期研究貢獻與未來發展方向
13.1 預期貢獻
23.	技術整合貢獻：將生成式 AI 的自然語言處理能力與地理資訊服務整合，建立從需求輸入到行程呈現的規劃流程。
24.	系統實務貢獻：以景點資料、交通資訊及行程規則檢核降低單純文字生成可能產生的錯誤。
25.	評估方法貢獻：透過基準組比較與量化指標，分析地理資訊及驗證機制對行程品質的影響。
以上為預期貢獻，最終應依實際完成的系統及實驗結果撰寫。
13.2 未來發展方向
•	個人化推薦：根據使用者興趣、過往選擇及同行對象調整景點排序。
•	多景點路線最佳化：在景點價值、交通時間、開放時段及每日行程長度之間建立最佳化目標與限制。
•	即時資訊整合：在資料來源允許的情況下，整合天氣、交通、營業時間及臨時公告。
•	多語言與行動裝置支援：擴大使用情境與可及性。
十四、正式指導建議
經檢視本專題之研究方向與預期應用，本人認為本研究具有良好的實務應用潛力，亦具備結合人工智慧、地理資訊與智慧觀光等跨領域技術的發展價值。
建議研究團隊在後續執行過程中，優先釐清研究問題與研究範圍，並以生成式人工智慧的自然語言理解及內容生成能力為基礎，結合可信的景點資料、地理座標、交通資訊與行程時間限制，建立具備實際使用價值的智慧旅遊規劃系統。
在系統設計方面，應重視各功能模組之間的整合，確保使用者需求、景點資料、AI 生成結果、地圖資訊及行程驗證機制能夠形成完整的作業流程。同時，應針對生成式 AI 可能產生的錯誤資訊、景點資料不完整、交通時間估算偏差及行程安排不合理等問題，設計適當的檢核與例外處理機制。
在研究方法方面，建議採用明確的實驗設計與量化評估指標，並透過不同規劃方式的比較，檢驗地理資訊整合及行程驗證機制對行程品質、規劃效率與使用者滿意度的影響。研究結果應以實際測試數據為依據，避免僅以系統功能展示或主觀描述作為研究成效的判斷標準。
在論文撰寫方面，應加強文獻探討與研究問題之間的關聯，明確說明系統設計的理論依據、技術選用理由、實驗結果及研究限制，並確保引用資料的正確性與學術規範。
指導結論：建議持續推動本專題，並將「生成式 AI 與地理資訊的有效整合」及「行程規劃品質的實證驗證」列為主要研究核心。
十五、導師總結：三項重要原則
26.	先求正確，再求智慧：景點資料與交通資訊必須可靠，不能只追求 AI 生成速度。
27.	先求可行，再求最佳化：先確保行程能在合理時間內完成，再考慮更複雜的路線演算法。
28.	先有證據，再下結論：所有關於系統優勢、效率提升及使用者滿意度的主張，都應有測試或實驗結果支持。
這三項原則將直接影響本專題最終的學術品質與實作成果。
